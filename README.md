# PSRDISP: A novel dispersive noise modeling framework
A single-pulsar noise analysis package to model dispersive processes using high-precision epoch-wise Dispersion Measure time series.

## Requirements
```
NUMPY
ASTROPY
PINT
MATPLOTLIB
SCIPY
EMCEE
CORNER
POCOMC

```
